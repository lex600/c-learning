# c-learning

我的 C 语言学习记录。

## 目录说明

| 文件夹 | 用途 |
| --- | --- |
| `course/` | 跟翁恺 C 语言课程写的练习代码 |
| `luogu/` | 洛谷刷题的题解 |
| `notes/` | 学习笔记 |
| `archive/` | Dev-C++ 时期的旧代码归档 |

## 命名约定

- 跟课代码：`course/2026-10-05-函数-判断素数.c`
- 洛谷题解：`luogu/P1046-陶陶摘苹果.c`
- 不要再用「未命名XX.c」这种名字，三个月后你自己都认不出

## 提交习惯

每次学完写一条提交，说明当天做了什么：

```
git add .
git commit -m "学习函数：写了一个判断素数的函数"
```

> 这个仓库不是作品集，是我自己的安全网和成长档案。
